# Периферия

Учебный сайт-каталог компьютерной периферии для лабораторной работы по веб-программированию. В каталоге представлены учебные модели мыши, клавиатуры и наушников.

**Статус: Лабораторная № 1 — в процессе.**

## Технологии

HTML5 и CSS3. Все страницы используют общий файл `css/style.css`, изображения находятся в папке `images/`. JavaScript, сторонние библиотеки и сборка не используются.

## Текущие страницы

- `index.html` — главная страница: информация о проекте и категории устройств.
- `catalog.html` — каталог с тремя карточками устройств.
- `mouse.html` — описание мыши Click M1, таблица характеристик и совет по выбору.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и запуск сервера не требуются. Для перехода к устройству выберите «Каталог», затем «Подробнее о мыши».

## Этап работы

Сейчас реализованы три страницы. В завершённой лабораторной планируются шесть страниц, а также аудио и видео; на текущем этапе они ещё не добавлены.
