# Периферия

Независимый каталог компьютерных устройств для рабочего пространства. Восемь страниц, адаптивная вёрстка и работающие инструменты выбора.

## Возможности

- Поиск по названию, категории, подключению и характеристикам.
- Фильтры по категории, просмотр избранного, сортировка.
- Сравнение до трёх устройств в отдельном диалоге.
- Избранное и сравнение сохраняются в браузере через localStorage.
- Подбор направления по задачам и типу подключения.
- Страницы трёх устройств, руководство, ответы на вопросы, видео и аудио.
- Мобильное меню, поддержка клавиатуры и prefers-reduced-motion.

## Запуск

Откройте `index.html` в браузере. Сайт не требует сборки и установки зависимостей.

Для локального HTTP-просмотра, если установлен Node.js:

```sh
node scripts/serve.cjs
```

Адрес: `http://127.0.0.1:8080`. Другой порт можно задать переменной окружения `PORT`.

## Структура

- `index.html` — главная.
- `catalog.html` — каталог с поиском и фильтрами.
- `mouse.html`, `keyboard.html`, `headphones.html` — устройства.
- `guide.html` — руководство, подбор и FAQ.
- `media.html` — видео и аудио.
- `about.html` — подход и назначение каталога.
- `css/style.css` — визуальная система и адаптивные стили.
- `js/app.js` — данные каталога и интерактивные возможности.
- `images/*-studio.webp`, `images/hero.webp` — созданные для сайта иллюстрации; оригинальные JPG сохранены.
- `media/` — исходные MP4 и WAV.

Данные трёх устройств находятся в `js/app.js`. При изменении характеристик следует синхронизировать соответствующую HTML-страницу устройства.

## Границы продукта

Это каталог с инструментами выбора, без оформления заказов, платежей и серверной базы данных. Аккаунты и внешняя аналитика не используются. Избранное сохраняется локально и не синхронизируется между устройствами. Если localStorage недоступен, выбор работает в памяти вкладки.

Визуальные иллюстрации созданы с помощью ImageGen. Медиафайлы сохранены в исходном формате; видео не выдаётся за тестирование модели каталога. Сайт готов к размещению на статическом хостинге. Автоматическое развёртывание не настроено.
