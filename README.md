# Периферия

Учебный сайт-каталог компьютерной периферии для лабораторной работы по веб-программированию. В каталоге представлены мыши, клавиатуры и наушники.

**Статус: Лабораторная № 1 — в процессе.**

## Технологии

HTML5 и CSS3. Все страницы используют общий файл `css/style.css`, изображения находятся в папке `images/`, видео и аудио — в `media/`. JavaScript, сторонние библиотеки и сборка не используются.

## Текущие страницы

- `index.html` — главная страница: информация о проекте и категории устройств.
- `catalog.html` — каталог с тремя карточками устройств.
- `mouse.html` — описание мыши Click M1, таблица характеристик и совет по выбору.
- `guide.html` — рекомендации по выбору мыши, клавиатуры и наушников, список проверок перед покупкой.
- `about.html` — назначение каталога и ссылки на его разделы.
- `media.html` — видео работы с клавиатурой и запись звука клавиш с проигрывателями.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и запуск сервера не требуются. Для перехода к устройству выберите «Каталог», затем «Подробнее о мыши».

## Этап работы

Реализованы шесть страниц, добавлены аудио и видео. Лабораторная остаётся в процессе до итоговой проверки и подготовки отчёта.
