Type K1

Текст, числа, сочетания клавиш. Полноразмерная клавиатура с цифровым блоком — когда привычный порядок помогает сосредоточиться.

Проводное USB 104 клавиши Цифровой блок

Твой выбор сохранится в этом браузере.

Характеристики Type K1

Тип клавиатуры Мембранная
Количество клавиш 104
Формат Полноразмерная, с цифровым блоком

Стоит проверить

Оцени место на столе, расположение символов и удобство положения кистей. Для подключения нужен совместимый USB-порт. Подробнее в руководстве.
